## Story

**As an** `lp-forge` user,
**I want** Phase 1 (`fetch + extract`) to invoke the vendored `design-md` skill and produce its 8+ output artifacts under our `outputs/lp-forge/{slug}/` directory,
**so that** subsequent phases have real `DESIGN.md`, `tokens.json`, `style-fingerprint.json`, `stack.json`, and `page.md` to consume.

## Acceptance Criteria

1. **AC-1 — Vendored design-md:** `vendor/design-md/` contains a **frozen copy** of `.claude/skills/design-md/` (full tree minus its own `node_modules/`, `outputs/`, and any `.git*` files). Commit includes a `VENDORED.md` documenting source commit SHA, copy date, and "DO NOT edit in place — re-vendor instead" policy.
2. **AC-2 — Vendor `npm install`:** `vendor/design-md/node_modules/` is gitignored; `lp-forge/package.json` has a `postinstall` script: `(cd vendor/design-md && npm install)` so a single `npm install` at the skill root bootstraps both.
3. **AC-3 — Adapter implementation (per Aria Amendment A-1: hybrid spawn+require model):** `lib/adapters/design-md-adapter.cjs` exports `async run(ctx)` that:
   - For the full pipeline: invokes vendored `node vendor/design-md/run.cjs --url <ctx.url> --out <ctx.outDir> --provider <ctx.provider> --model <ctx.model>` as a child process
   - For shared utilities: directly `require()`s `vendor/design-md/lib/utils.cjs` (slugify, color/px parsing) and `vendor/design-md/lib/llm.cjs` (provider abstraction) — DO NOT duplicate these into `lp-forge/lib/`
   - Streams design-md stdout to `lp-forge` stdout via `lib/logger.cjs` (per A-5), prefixed `[design-md]`
   - Returns `{ designMd: '<path>/DESIGN.md', tokens: parsedYaml, fingerprint: parsedJson, stack: parsedJson, pageMd: '<path>/inputs/page.md' }`
   - Maps design-md exit codes 2/4/5/6/7 to `lp-forge` exit codes (forwards 4 directly; wraps others under code 7 with reason field)
   - **DevNote:** future epic should propose upstream PR exposing `runPipeline(opts)` as a library function; until then, child_process is the contract.
4. **AC-4 — Phase cache implemented (per Aria gap G-3):** Replaces 2.1 stub in `lib/cache.cjs`:
   - `checkPhaseCache('fetch-extract', ctx)` returns hit if all of `{slug}/DESIGN.md`, `tokens.json`, `style-fingerprint.json` exist AND `mtime < 24h` AND **cache-key hash matches**
   - **Cache key** is `sha256(url + lang + provider + model + dataFilesHash)` where `dataFilesHash` = sha256 of concatenated mtimes of `data/category-to-direction.yaml`, `data/aesthetic-lint-rules.yaml`, `data/forbidden-fonts.yaml`, `data/curated-font-pairs.yaml` — invalidates cache when ops update rule files between runs
   - Cache key stored in `{slug}/_cache-key.txt` alongside artifacts
   - `writePhaseCache(phase, ctx, output)` is no-op for adapter (design-md writes directly to outDir); but writes `_cache-key.txt`
   - Test: re-running same URL within 24h skips child process; logs `[reuse] fetch-extract cached`. Updating `data/category-to-direction.yaml` mtime invalidates cache on next run.
5. **AC-5 — Content-gate hardening (per Aria Amendment A-2):** When design-md exits 4 (content-validation gate failed), adapter:
   - Captures stderr and design-md's content-gate reason
   - If `ctx.allowPlaywright === true`:
     - **Checks `require.resolve('playwright')` before invoking** — if Playwright not installed (per `optionalDependencies`), exits with code **12** and hint: `"Playwright fallback requested but not installed. Run: cd .claude/skills/lp-forge && npm run install-playwright"`
     - If installed, invokes `lib/playwright-fallback.cjs` (this story creates the stub; full impl Story 2.3 follow-up or deferred)
   - If false, exits `lp-forge` with code 4 and prints actionable hint: `"Site appears to use client-side rendering or has bot detection. Retry with --allow-playwright."`
6. **AC-6 — Playwright fallback stub:** `lib/playwright-fallback.cjs` exists; exports `async run(ctx)` that:
   - Wraps `require('playwright')` in try/catch — throws clear `Error('Playwright not available')` if module not installed (code 12)
   - Otherwise currently throws `Error('Playwright fallback not yet implemented — Story 2.3 follow-up')` (code 4)
   - Adapter catches both errors and emits appropriate exit code + hint
7. **AC-7 — `--no-reuse` flag:** When passed, cache is bypassed; design-md re-runs cold; cache is still **written** (just not read).
8. **AC-8 — Telemetry fields:** `run-telemetry.json` Phase 1 entry includes: `model`, `provider`, `cost` (if openrouter), `cacheHit: bool`, `durationMs`, `tokensExtracted: N`, `fingerprint: <archetype>`, `stack: [<detected>]`.
9. **AC-9 — Tests:**
   - Unit: adapter's exit-code mapping (mocked child process)
   - Unit: cache freshness logic (mocked mtime)
   - Integration: against `tests/fixtures/restaurant.example.com/` — recorded HTML/CSS via local fixture server — adapter runs end-to-end, produces expected files
10. **AC-10 — slug semantics preserved:** Adapter uses the `slug` already computed by orchestrator (from 2.1's `slugifyUrl()`); design-md's internal slugger is NOT invoked — we pass an explicit `--out`.
11. **AC-11 — Quality gates pass:** `npm run lint`, `npm test`, CodeRabbit pre-commit all green.

## Dev Notes

- **Why vendor not symlink:** reproducibility. Operator's `.claude/skills/design-md/` may be a different version. Frozen vendor = deterministic builds. To upgrade: re-vendor explicitly via documented procedure (next story or a script in `scripts/revendor.cjs` — TBD).
- **child_process vs require():** design-md's `run.cjs` is a CLI, not a library export. Cleanest integration = spawn it. Future v2 may refactor design-md to expose a library API, but that's design-md's epic, not ours.
- **Recording fixture HTTP:** use `tests/serve-fixture.cjs` (simple Express) over `nock` — design-md's axios calls are easier to redirect via a local HTTP server than to mock. Fixture lives in `tests/fixtures/restaurant-fixture/{index.html,styles.css,...}`.
- **`vendor/design-md/`'s own outputs land in our `outDir`** because we pass `--out` explicitly. Verify: design-md must respect `--out`. (Per design-md README it does.)

### Risks
- Vendoring goes stale. **Mitigation:** add `vendor/design-md/VENDORED.md` with date + commit; add a CI check in Story 2.6 that warns if upstream design-md has commits newer than vendored SHA.
- design-md's own `node_modules/` bloat. **Mitigation:** confirmed gitignored; lockfile is committed for reproducibility.
