# Design Scoring Rubric (Story 2.4)

Each of 5 design axes scored 1-10 by analysis-doc.cjs. Used in `analysis-report.md` §4.

## Axis: Typography

- **9-10:** Distinctive display + refined body pairing; non-default fonts; consistent rhythm
- **7-8:** Solid font choices; one minor inconsistency
- **5-6:** Generic but functional (e.g., Inter only); inconsistent sizing
- **3-4:** AI-default fonts (Roboto/Arial/system); inconsistent
- **1-2:** Multiple competing display fonts; no rhythm
- **n/a:** site uses no custom typography

## Axis: Color & Palette

- **9-10:** Committed dominant color + sharp accent; deliberate use of neutrals
- **7-8:** Coherent palette; one decision lacking conviction
- **5-6:** Multi-color but pleasant (3+ accents)
- **3-4:** Generic SaaS palette (blue+purple); no commitment
- **1-2:** Color noise; many competing hues
- **n/a:** monochrome with no accent

## Axis: Spacing & Composition

- **9-10:** Generous whitespace, intentional asymmetry, clear visual hierarchy
- **7-8:** Tight but breathing; consistent grid
- **5-6:** Acceptable; some crowding in sections
- **3-4:** Cramped, no whitespace strategy
- **1-2:** Walls of text; no hierarchy
- **n/a:** mostly empty page

## Axis: Motion & Interactivity

- **9-10:** One memorable hero animation; subtle hover states; no scroll noise
- **7-8:** Restrained motion; appropriate timing
- **5-6:** Some motion; occasionally distracting
- **3-4:** Scroll triggers everywhere; transitions on every element
- **1-2:** Aggressive parallax; auto-play media; click-bait micro-interactions
- **n/a:** static page, no motion

## Axis: Backgrounds & Detail

- **9-10:** Atmospheric textures/gradients matching aesthetic; intentional grain or noise
- **7-8:** Solid colors used with purpose; one detail done with care
- **5-6:** Flat backgrounds; could use atmosphere
- **3-4:** Default gradients (purple-blue-pink AI slop); no detail work
- **1-2:** Distracting backgrounds (auto-playing video); visual chaos
- **n/a:** all white/solid

---

## Note for graders

- A score of **n/a** is OK and honest (huashu §1.a no-invention principle)
- Score 5 is the "AI default" — anything below indicates active anti-pattern; anything above indicates real design judgment
- Round numbers preferred (e.g., 7 not 7.3) — readers don't need decimals
